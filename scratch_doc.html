2. REST API Endpoints Specification

A. Authentication & Session

Base Endpoint: /api/auth or Supabase Auth API Method: POST /auth/v1/token?grant_type=password Headers: apikey: [SUPABASE_KEY], Content-Type: application/json Request Body: { "email": "employee@example.com", "password": "secure_password" } Response (200 OK): { "access_token": "jwt_access_token", "refresh_token": "jwt_refresh_token", "user": { "id": "uuid", "email": "employee@example.com" } }

B. User Profile

Method: GET /api/user/profile Headers: Authorization: Bearer [ACCESS_TOKEN] Response (200 OK): { "id": "uuid", "name": "Employee Name", "email": "employee@example.com", "role": "EMPLOYEE", "department": "Engineering" }

C. Geofence Office Locations

Method: GET /api/locations Headers: Authorization: Bearer [ACCESS_TOKEN] Response (200 OK): [ { "id": "loc_1", "name": "Head Office", "latitude": 6.9271, "longitude": 79.8612, "radius": 100.0 } ]

D. Attendance Punch & Logs

Method: GET /api/attendance Headers: Authorization: Bearer [ACCESS_TOKEN] Response (200 OK): Array of user attendance punch logs Method: POST /api/attendance Headers: Authorization: Bearer [ACCESS_TOKEN], Content-Type: application/json Request Body: { "locationId": "loc_1", "latitude": 6.92712, "longitude": 79.86125, "type": "CHECK_IN" // or "CHECK_OUT" } Response (200 OK): { "success": true, "message": "Attendance punched successfully", "isLate": false }

E. QR Code Gate / Supervisor Punch

Method: POST /api/admin/scan-punch Headers: x-gate-passcode: HR (or Bearer Token) Request Body: { "userId": "user_uuid", "locationId": "location_uuid" } Response (200 OK): { "success": true, "punchType": "CHECK_IN", "userName": "Employee Name" }

F. Leave Management

Method: GET /api/leave-balances Headers: Authorization: Bearer [ACCESS_TOKEN] Response: Array of leave types, allocated, used, and remaining count. Method: POST /api/leave-requests Headers: Authorization: Bearer [ACCESS_TOKEN], Content-Type: application/json Request Body: { "leaveTypeId": "type_uuid", "startDate": "2026-10-15", "endDate": "2026-10-16", "reason": "Personal Leave" }
