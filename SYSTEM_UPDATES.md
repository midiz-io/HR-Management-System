## 📅 2. Employee Join Date Tracking
To improve tenure calculations and leave entitlement tracking, a protected "Join Date" field has been added to the User Profile.

**System Policy & Privacy Rules:**
- **Admin/Super Admin Only**: Only authorized personnel can edit or update an employee's official join date through the *Global User Management* interface.
- **Permanent Records**: Once set, the join date is permanently synchronized with the database to prevent data loss.
- **Privacy Enforcement**: Employees can view their official join date on their profile but cannot modify it, ensuring the integrity of company records.
