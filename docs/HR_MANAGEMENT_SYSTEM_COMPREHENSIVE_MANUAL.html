1. Executive Summary & Core Value Proposition

The AttendX HR & Workforce Management System is a cloud-native, enterprise-grade Human Capital Management (HCM) platform engineered to streamline workforce tracking, attendance authentication, smart roster scheduling, multi-tiered leave workflows, overtime governance, employee welfare operations, and automated payroll calculation for modern distributed organizations.

Core Architectural Philosophy:

AttendX bridges physical workplace presence and digital governance using real-time geofencing algorithms, dynamic cryptographic QR gate passes, automated probation/accrual tracking, and complete financial audit trails. It eliminates attendance fraud (buddy punching), automates complex scheduling across geographical branches, and provides unified corporate oversight.

3. Geofencing Attendance & Location Intelligence Engine

The attendance verification subsystem enforces strict geographical validation using the spherical Haversine formula to ensure employees are physically present within authorized office coordinates before a punch is accepted.

Haversine Distance Formulation

The system evaluates coordinates (lat1, lon1) from the client device against office boundaries (lat2, lon2): 

const R = 6371e3; // Earth radius in meters
const phi1 = (lat1 * Math.PI) / 180;
const phi2 = (lat2 * Math.PI) / 180;
const deltaPhi = ((lat2 - lat1) * Math.PI) / 180;
const deltaLambda = ((lon2 - lon1) * Math.PI) / 180;

const a = Math.sin(deltaPhi / 2) * Math.sin(deltaPhi / 2) +
          Math.cos(phi1) * Math.cos(phi2) *
          Math.sin(deltaLambda / 2) * Math.sin(deltaLambda / 2);
const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
const distance = R * c; // Distance in meters

const isWithinGeofence = distance <= allowedRadiusMeters;

4. Multi-Shift Scheduling & Bulk Roster Management

Managing shifts across multiple branches and departments is streamlined through the newly developed Bulk Roster Engine:

Scheduling Mode Behavior & Execution Mechanics Target Use Case
Daily Repeat Applies the selected shift to every sequential day across the configured date window without day-of-week skipping. Continuous operation sites, security officers, 24/7 technical shifts.
Repeat by Shift Days Filters and matches the default standard working days predefined in the Shift profile (e.g., Monday through Friday). Headquarters corporate staff, standard operational departments.
Day-by-Day (Custom) Allows managers to manually toggle active operational days (e.g., Mon, Wed, Sat) with ongoing recurrence or fixed deadlines. Part-time employees, rotational shift engineers, medical staff.
Off-Day & Shift Swap Governance:

Employees can initiate formal OffDayRequest submissions. The workflow enforces a two-tier review hierarchy: the Department Sectional Head / Recommender validates team capacity before forwarding to HR / Reviewer for final roster mutation.

5. Leave Governance, Smart Probation & Gate Passes

The leave management subsystem balances employee flexibility with operational continuity through granular leave type balances and probation protection rules:

Smart Probation Leave Policy

  • 3-Month Probation Window: Calculated automatically from User.joinDate.
  • Half-Day Eligibility: Employees during their initial 90 days are entitled to one half-day leave per calendar month.
  • Full-Day Lock: Full-day annual and casual leaves remain locked until the probation period completes, preventing policy violations.
  • Dynamic Countdown: Portal displays the exact days remaining until full leave eligibility is unlocked.

Gate Passes & Short Leaves

  • Gate Pass Workflows: Submissions with official/personal designations, departure time, and vehicle/contact metadata.
  • Security Gate Check: Dedicated QR Code verification endpoint at security checkpoints records departure and re-entry punches.
  • Short Leave Quota: Limits short absences (up to 2 hours) to statutory limits without deducting full annual balances.
  • Real-time Status: Managers monitor pending gate pass checkouts directly on the operational dashboard.

11. Security, Role-Based Access Control & Database Backup

Role-Based Access Control (RBAC)

  • SUPER_ADMIN: Unrestricted system control, database backups, financial settings, and user provisioning.
  • ADMIN: HR management, leave reviews, roster generation, and payroll approvals.
  • MANAGER: Branch roster adjustments, team attendance auditing, and gate pass approvals.
  • SECTIONAL_HEAD: Department-level task delegation and off-day recommendations.
  • EMPLOYEE: Self-service punches, payslip downloads, leave/OT filings, and welfare orders.

Automated Database Backup Engine

  • Automated SQL Snapshots: Full table schemas, relational data dumps, and foreign key cascades.
  • Dual Redundancy: Local disk storage + automated Google Drive cloud replication.
  • Point-in-Time Recovery: Soft-delete trash archive allows instant recovery of deleted users or shifts without database downtime.
  • Secure Vault: Sensitive keys encrypted at rest using industry-standard protocols.
