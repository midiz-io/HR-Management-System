# Today's Updates Summary - Geofencing Attendance System

This is a simple overview of the new features and improvements added today.

### 1. New Bulk Roster Management
A new tool that makes scheduling much faster:
- **Group by Location**: Quickly find employees based on their work location.
- **Multiple Selection**: Select many employees at once to assign a schedule.
- **Improved "Repeat" Options**:
  - **Daily Repeat**: Applies the shift to every day of the week.
  - **Repeat by Shift Days**: Follows the common working days for that shift (e.g., Mon-Fri).
  - **Day by Day (Custom)**: Pick specific days (e.g., Mon, Wed, Fri) manually.
- **Flexible Dates**: Set a start date and an optional end date (or keep it ongoing).

### 2. Location Tracking for Employees
- Employees can now be officially linked to specific work locations.
- Managers can use this to filter lists and see reports for specific branches or sites.

### 3. New Leave Rules for New Employees
We've updated the rules for employees who joined recently (first 3 months):
- **Half-Day Eligibility**: Even during probation, employees can now take **one half-day leave per month**.
- **Full-Day Restriction**: Full-day leaves are still reserved for after the 3-month probation period is completed.
- **Better Guidance**: The system now shows a clear message telling employees exactly when they will become eligible for full-day leaves.

### 4. Smart System Logic
- **Accurate Attendance**: The system now correctly calculates if someone is "Late" or "Present" based on whichever flexible repeat pattern was assigned to them.
- **Improved Reporting**: Missing attendance (Absent) reports now filter by location perfectly.
- **Dashboard Stability**: Fixed various small errors to ensure the dashboard works smoothly without interruptions.
